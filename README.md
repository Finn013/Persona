# Persona — браузер с изолированными профилями

Несколько аккаунтов на одних и тех же сайтах — **одновременно и без переключения**.
У каждого профиля свои куки, входы, localStorage и кэш. Каждый профиль открывается своим окном
в «Недавних», так что все они живут параллельно, как отдельные браузеры.

## Возможности

- **Профили** — название, цвет, стартовая страница. Создавай сколько нужно.
- **Ярлыки вместо PWA** — «⋮ → Ярлык на рабочий стол»: сайт + профиль на главном экране.
  Можно поставить, например, три ярлыка одного сайта с тремя разными аккаунтами — каждый откроется отдельным окном.
- **Подмена устройства** на профиль: модель, версия Android, экран, плотность пикселей, ядра,
  архитектура, память, видеочип (WebGL), точки касания, платформа, языки, часовой пояс, User-Agent.
  Пустые поля показывают серым настоящие значения телефона.
- **«Прикинуться…»** — готовые устройства: Pixel 8, Pixel 7a, Galaxy S23, Galaxy A54,
  Redmi Note 12, Xiaomi 13, OnePlus 11, Galaxy Tab S9.
- Вход через Google и всплывающие окна OAuth внутри профиля, загрузка файлов, скачивания, видео на весь экран, «Версия для ПК».
- Стереть данные профиля или удалить его одной кнопкой.

## Требования

- Android 10+
- Свежий **Android System WebView** (или Chrome) из Play Маркета — нужен режим нескольких профилей.
  Если он не поддерживается, приложение предупредит.

## Ограничения

- IP-адрес и сетевой (TLS) отпечаток не подменяются — для этого нужен прокси/VPN.
- Push-уведомления от сайтов не приходят (ограничение WebView).
- Подмена работает на уровне JavaScript; продвинутые антифрод-системы могут её заметить.

## Сборка

APK собирается GitHub Actions при каждом пуше в `main` и прикладывается к релизам.
